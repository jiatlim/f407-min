# f407-min

STM32F407 最小系统实验仓。目的只有一个：暂定。

实验， 不保证可复用。

## 进度

| 交付物 | 内容 | 状态 |
|---|---|---|
| **A1 ** | 寄存器点灯 → TIM1 互补 PWM + 死区 → ADC 由定时器触发 → 扫过整个周期 | 进行中（第 1 步） |

## 硬件

- MCU：STM32F407ZGT6（144 脚 / 1MB Flash）— 板子到货后按丝印核对型号与晶振频率
- 调试器：CMSIS-DAP，SWD 四线（SWDIO / SWCLK / GND / 3V3）
- 仪器：示波器（双通道）、逻辑分析仪（8 通道）

## 工具链

- Keil MDK 5 + ARM Compiler 6
- **不用 HAL，不用 CubeMX 生成代码**。A1 全程直接操作寄存器，头文件只有 `stm32f4xx.h`

## 目录

一个交付物一个目录（`a1-*`、`a4-*`…），A1 第 1 步开始时建。
